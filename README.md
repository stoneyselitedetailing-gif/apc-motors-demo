# APC Motor Group website concept

A static preview of the proposed APC Motor Group website, for presenting to the owner. It is not the live site:

- a banner across the top marks it as a concept preview
- search engines are told not to index it (`robots.txt`, a `noindex` meta tag and an `X-Robots-Tag` header)
- the enquiry forms show a thank-you message but send nothing

## Preview on Vercel

Import this repository in Vercel and deploy. No build settings are needed.
